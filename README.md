## 🎯 О проекте

**WhiteListChecker** — это веб-приложение, которое помогает определить, **включены ли у вашего провайдера «белые списки»** — режим ограничения доступа, при котором работают только одобренные российские сервисы, а зарубежные сайты блокируются.

Приложение работает **прямо в браузере**, не требует установки и не отправляет ваши данные на сторонние серверы (кроме публичных API для определения IP-адреса).

## ✨ Возможности

### 🔍 Диагностика сети
- Определение текущего режима: **Белые списки** / **Без ограничений** / **Нет соединения** / **Нестабильная сеть**
- Проверка доступности через три независимых ресурса: **Яндекс**, **Google**, **Cloudflare**
- Измерение **пинга** (задержки) до каждого сервиса с цветовой индикацией:
  - 🟢 менее 100 мс — отличное соединение
  - 🟡 100–300 мс — среднее
  - 🔴 более 300 мс — плохое
- Мини-график пинга — визуализация последних восьми замеров

### 🔄 Автоматический скан
- Автоматическая проверка сети с настраиваемым интервалом
- Выбор единицы измерения: **секунды / минуты / часы**
- Быстрые пресеты для типичных значений
- **Уведомления Windows** при смене статуса сети — работают даже в фоне
- Настройки сохраняются между сессиями

### 📶 Информация о соединении
- **Оператор связи** — определяется автоматически
- **IP-адрес** — скрыт по умолчанию, показывается по нажатию кнопки
- **Локация** — город, регион, страна
- Быстрое копирование IP в буфер обмена

## 💡 Часто задаваемые вопросы

**Почему IP-адрес скрыт?**
Чтобы вы случайно не «засветить» его на скриншоте или при демонстрации экрана. Нажмите «Показать», когда это нужно.

**Что значит «Белые списки активны»?**
Это означает, что ваш оператор связи включил режим ограничения доступа в интернет — доступны только одобренные российские сервисы, зарубежные сайты заблокированы.

**Почему уведомления не приходят?**
Убедитесь, что сайт открыт по HTTPS, а уведомления разрешены в настройках браузера. В разделе «Настройки» нажмите «Запросить разрешение» и проверьте статус в индикаторе ниже.

**Сохраняется ли история между сессиями?**
Да, история хранится локально в вашем браузере и доступна при следующем открытии сайта.

**Можно ли использовать без интернета?**
Нет, для проверки статуса сети требуется подключение. Но интерфейс и справочник белых списков доступны всегда.
